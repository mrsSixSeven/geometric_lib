# Библиотека вычисления геометрических характеристик фигур

## Общее описание

Библиотека содержит функции для вычисления площади и периметра геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Описание функций

### `circle.area(r)`

Вычисляет площадь круга

- Принимает: `r` (`int`) - радиус круга.
- Возвращает: `float` - площадь круга.

Пример:

```python
print(circle.area(3))
```

### `circle.perimeter(r)`

Вычисляет длину окружности.

- Принимает: `r` (`int`) - радиус круга.
- Возвращает `float` - длина окружности

Пример:

```python
print(circle.perimeter(3))
```

### `rectangle.area(a, b)`

Вычисляет площадь прямоугольника.

- Принимает: `a` (`int`), `b` (`int`) - длины сторон прямоугольника.
- Возвращает `int` - площадь прямоугольника.

Пример:

```python
print(rectangle.area(3, 5))
```

### `rectangle.perimeter(a, b)`

Вычисляет периметр прямоугольника.

- Принимает: `a` (`int`), `b` (`int`) - длины сторон прямоугольника.
- Возвращает `int` - периметр прямоугольника.

Пример:

```python
print(rectangle.perimeter(3, 5))
```

### `square.area(a)`

Вычисляет площадь квадрата.

- Принимает: `a` (`int`) - длина стороны квадрата.
- Возвращает `int` - площадь квадрата.

Пример:

```python
print(square.area(3))
```

### `square.perimeter(a)`

Вычисляет периметр квадрата.

- Принимает: `a` (`int`) - длина стороны квадрата.
- Возвращает `int` - периметр квадрата.

Пример:

```python
print(square.perimeter(3))
```

### `triangle.area(a, h)`

Вычисляет площадь треугольника.

- Принимает: `a` (`int`) - длина основания треугольника, `h` (`int`) - длина высоты треугольника.
- Возвращает `float` - площадь треугольника.

Пример:

```python
print(triangle.area(3,5))
```

### `triangle.perimeter(a, b, c)`

Вычисляет периметр треугольника.

- Принимает: `a` (`int`), `b` (`int`), `c` (`int`) - длины сторон треугольника.
- Возвращает `int` - периметр треугольника.

Пример:

```python
print(triangle.perimeter(1, 2, 3))
```
