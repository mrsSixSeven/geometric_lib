# Библиотека вычисления геометрических характеристик фигур

## Общее описание

Библиотека содержит функции для вычисления площади и периметра геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Описание функций

### `circle.area(r)`

Вычисляет площадь круга

- Принимает: 

`r` - радиус круга.
- Возвращает: 

Площадь круга, вычисленная по формуле pi * r * r.

Пример:

```python
print(circle.area(3))
```

### `circle.perimeter(r)`

Вычисляет длину окружности.

- Принимает: 

`r` - радиус круга.
- Возвращает: 

Длина окружности, вычисленная по формуле 2 * pi * r.

Пример:

```python
print(circle.perimeter(3))
```

### `rectangle.area(a, b)`

Вычисляет площадь прямоугольника.

- Принимает:

 `a` - длина первой стороны прямоугольника.

`b` - длина второй стороны прямоугольника.
- Возвращает:

 Площадь прямоугольника, вычисленная по формуле a * b.

Пример:

```python
print(rectangle.area(3, 5))
```

### `rectangle.perimeter(a, b)`

Вычисляет периметр прямоугольника.

- Принимает: 

`a` - длина первой стороны прямоугольника.

`b` - длина второй стороны прямоугольника.
- Возвращает:

Периметр прямоугольника, вычисленный по формуле (a + b) * 2.

Пример:

```python
print(rectangle.perimeter(3, 5))
```

### `square.area(a)`

Вычисляет площадь квадрата.

- Принимает: 

`a` - длина стороны квадрата.
- Возвращает: 

Площадь квадрата, вычисленная по формуле a*b.

Пример:

```python
print(square.area(3))
```

### `square.perimeter(a)`

Вычисляет периметр квадрата.

- Принимает:

 `a` - длина стороны квадрата.
- Возвращает:

 Периметр квадрата, вычисленный по формуле 4 * a.

Пример:

```python
print(square.perimeter(3))
```

### `triangle.area(a, h)`

Вычисляет площадь треугольника.

- Принимает:

 `a` - длина основания треугольника
 
 `h` - длина высоты треугольника.
- Возвращает:

 Площадь треугольника, вычисленную по формуле a * h / 2

Пример:

```python
print(triangle.area(3,5))
```

### `triangle.perimeter(a, b, c)`

Вычисляет периметр треугольника.

- Принимает: 

`a` - длина первой стороны треугольника.

`b` - длина второй стороны треугольника.

`c`- длина третьей стороны треугольника.
- Возвращает:

Периметр треугольника, вычисленный по формуле a + b + c.

Пример:

```python
print(triangle.perimeter(1, 2, 3))
```
